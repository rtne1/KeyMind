# Code of conduct

We want a constructive and respectful environment for contributors and users.

- Be professional and considerate, including when disagreeing about a technical decision.
- Welcome questions and provide actionable, technically grounded feedback.
- Do not harass, threaten, impersonate, or publish someone else's private information.
- Do not post raw typing traces, passwords or private diagnostics.

Maintainers may edit or remove content that violates these expectations. Report conduct issues privately to repository maintainers rather than escalating public threads. This policy applies to repository issues, pull requests and project discussion spaces.
