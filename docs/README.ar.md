## نبذة

KeyMind برنامج يعمل في الخلفية على Windows، ويحلل تخطيط لوحة المفاتيح ويحاول تصحيح الكلمات التي كُتبت بتخطيط لغة مختلف. يدعم التصحيح التلقائي والتحويل اليدوي والقواميس الإضافية ولوحة التشخيص.

**مثال:** عند كتابة `lpl]` باللوحة الإنجليزية ثم الضغط على المسافة، قد يحولها البرنامج إلى `محمد` عند تفعيل التصحيح التلقائي.

## التشغيل

1. نزّل مجلد المشروع كاملًا، مع الاحتفاظ بمجلدات `src` و`data` و`assets`.
2. أغلق أي نسخة تعمل من KeyMind بجانب الساعة.
3. شغّل `START-KEYMIND.cmd` على Windows؛ سيبني البرنامج من المصدر ثم يشغله.
4. فعّل المحرك والتصحيح التلقائي من الإعدادات.
5. اختبر البرنامج أولًا داخل Notepad، واستخدم لوحة التشخيص عند حدوث مشكلة.

يتطلب البناء التقليدي مترجم C# الخاص بـ .NET Framework. يوجد كذلك مشروع `KeyMind.csproj` يستهدف .NET 10 على Windows.

## الاختبارات

```powershell
python tests/verify_package.py
python tests/verify_background_listener.py
python tests/eval_accuracy.py
.\TEST-ENGINE.cmd
```

الاختبار الأخير خاص بـ Windows؛ نجاح اختبارات Python لا يثبت عمل لوحة المفاتيح في كل التطبيقات.

## الخصوصية

**مهم:** يعمل البرنامج بواسطة مراقبة أحداث لوحة المفاتيح على مستوى النظام. قد لا يستطيع اكتشاف جميع خانات كلمات المرور، خصوصًا في المتصفحات. أوقف البرنامج أو أغلقه أثناء كتابة كلمات المرور أو البيانات الحساسة. لا تنشر ملفات التشخيص أو القواميس الشخصية دون مراجعتها.

تُحفظ الإعدادات في `%LOCALAPPDATA%\KeyMind\settings.json`، وقد تُسجل أخطاء التطبيق في `%LOCALAPPDATA%\KeyMind\error.log`.
