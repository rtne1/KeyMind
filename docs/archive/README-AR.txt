KeyMind 3.0 — مراقبة الكيبورد والتصحيح بين العربية والإنجليزية (نسخة اختبار)
============================================================================

التثبيت والتشغيل:
1) أغلق KeyMind من الأيقونة الموجودة بجوار ساعة Windows > Exit.
2) فك الضغط إلى D:\KeyMind-v3.0 ليكون المسار D:\KeyMind-v3.0\KeyMind.
3) شغّل D:\KeyMind-v3.0\KeyMind\START-KEYMIND.cmd.
4) إذا ظهر أي خطأ تجميع راجع Build-Log.txt؛ يتطلب مترجم .NET Framework 4.x من Windows.
5) تبقى نافذة التطبيق أو أيقونته بجانب الساعة أثناء عمل التصحيح.

اختبار تصحيح خارج التطبيق (ليس داخل نافذة الاختبار):
- افتح Notepad، وحوّل الكيبورد إلى الإنجليزية.
- اضغط المفاتيح l p l ] ثم Space؛ المطلوب تحويل lpl] إلى محمد.
- حوّل الكيبورد إلى العربية، واضغط مفاتيح l o c a l ثم Space؛ المطلوب تحويل مخؤشم إلى local.
- راجع الإعدادات: المحرك مفعّل، والتصحيح التلقائي مفعّل.
- إذا لم يتغير النص: افتح صفحة «تشخيص الكتابة» وانقر «نسخ تقرير التشخيص».

اختصارات:
Ctrl + Alt + Space  محاولة تحويل ذكي
Ctrl + Alt + Shift + Space  تحويل حرفي إجباري للكلمة المكتوبة
Ctrl + Alt + Z  تراجع عن آخر تحويل
Ctrl + Alt + P  إيقاف / استئناف

فحص النتائج:
Hook NOT INSTALLED => مشكلة تثبيت المستمع على مستوى النظام.
Physical keys ثابت => مستمع الكيبورد لا يستقبل الضغطات في التطبيق الخارجي؛ جرّب «إعادة تشغيل المراقبة» من التشخيص.
Spaces يزيد، Candidates ثابت => مشكلة في تتبع الكلمة أو قاموس الثقة أو التخطيط.
Candidates يزيد، Replacements ثابت => مشكلة التركيز أو إدخال النص SendInput.
Failures يزيد => افحص Last action؛ ربما منع Windows إرسال النص للتطبيق.

التصحيح لا يترجم المعنى؛ يعتمد على مواقع الأزرار المادية لتخطيط Arabic 101 و US QWERTY.
المحرك يحافظ على الكلمات الصحيحة ويرفض التصحيح الآلي عند غموض المقصود.

الخصوصية: لا تُحفظ الكلمات المكتوبة ولا تُرفع إلى الإنترنت، ولكن الأداة تتلقى
أحداث لوحة المفاتيح على مستوى النظام أثناء تشغيلها. قد لا تتعرف على جميع
حقول كلمات المرور في المتصفحات الحديثة؛ أوقفها عند إدخال بيانات حساسة.

هذا الإصدار يفصل مستمع الكيبورد عن واجهة التطبيق، ويُعيد تسجيل المستمع كل 20 ثانية إذا أوقفه ويندوز بصمت.

تنبيه صريح: اختُبرت الملفات والتحويلات اختبارًا ثابتًا في بيئة لينكس،
ولكن لم يمكن تجميع النسخة أو تجربتها داخل Chrome/Windows فعلي.
إن استمرت المشكلة فالخطوة الحاسمة هي تقرير التشخيص، وليس تبديل القواميس.
